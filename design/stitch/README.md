# Pamir Motoride Stitch design source

The files in this folder are the desktop and mobile HTML exports, design specification, and reference screenshots supplied by the site owner on 2026-09-25. They are retained for visual comparison. The live site is implemented in `src/` as Next.js components with localized routes and the real request form.

The Stitch HTML is a static design prototype and contains example inventory, prices, schedules, phone numbers, and promotional claims that are not verified. Do not publish those example claims as business facts. Hero videos are referenced from the supplied design with local image fallback.
